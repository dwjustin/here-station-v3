# 공유 형식

아래 항목은 합의할 목록이며, 확정된 JSON 스키마나 구현된 API가 아니다.

## 지도

- 역 ID, 지도 버전, 스키마 버전
- 좌표 원점, 축 방향, 거리 단위, 높이와 층의 관계
- 보행 영역과 연결 정보, 출구·계단·엘리베이터
- 원본 GLB 좌표와 지도 좌표의 관계
- 표시용 GLB가 있다면 그 파일과 지도 JSON의 관계

기존 `nav/core.js`는 `x,z`를 평면, `h`를 높이로 사용한다. 새 형식을 정할 때 기존 데이터와의 변환도 함께 정한다.

## API

- 역 검색과 역 상세 조회
- 지도 버전과 파일 다운로드 주소 조회
- 경로 요청: 역 ID, 지도 버전, 출발 위치, 목적지, 이동 조건
- 경로 응답: 사용한 지도 버전, 경로 좌표, 층별 구간, 안내 지점
- 오류: 지도 버전 불일치, 출발 위치 부적합, 경로 없음

프론트와 서버는 같은 지도 버전을 사용한다. A*의 거리·비용과 휴리스틱도 같은 단위를 따른다. 확정된 HTTP 형식은 FastAPI의 OpenAPI 문서와 함께 관리한다.
