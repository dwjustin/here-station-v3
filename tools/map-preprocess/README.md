# 지도 전처리

GLB에서 보행 가능한 영역, 높이, 층, 출구·계단·엘리베이터 등을 추출하는 도구를 둔다.

이 도구가 Node.js를 사용해도 API 서버는 FastAPI를 사용할 수 있다. 층별 PNG는 만들지 않는다.

원본 GLB와 생성한 전체 지도는 스토리지에 보관한다. 원본은 다시 전처리할 수 있도록 남긴다. 레포에는 도구, 작은 합성 예시와 형식 문서를 둔다.

전처리 결과는 `contracts/`에서 합의한 좌표·필드·버전을 따라야 한다.

만든 지도 JSON은 쓰기 전에 `tools/map-check/`로 자동 점검한다 (FAIL이면 종료 코드 1).
