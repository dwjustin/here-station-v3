# 협업

작업은 `main`에서 기능 브랜치를 만들어 진행한다. 예: `feat/mobile-navigation`, `feat/api-routing`, `feat/map-preprocess`.

담당자는 자신의 폴더에서 작업하되 다른 담당자와 주고받는 데이터가 바뀌면 먼저 `contracts/`에 제안한다. PR에는 바뀐 동작, API·지도 형식의 변경, 확인 방법을 적는다.

모바일 담당자는 센서·위치 추정·화면 코드를 구분하고, 백엔드 담당자는 HTTP·경로 함수·파일 읽기를 구분한다. 전처리 담당자는 작은 합성 지도로 출력 형식을 확인한다.

실제 지도·대용량 모델과 비밀 키는 커밋하지 않는다.
